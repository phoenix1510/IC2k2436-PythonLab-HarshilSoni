# Python Lab: Naive vs. Optimized Algorithms

In this lab, I explored how choosing the right algorithm can significantly affect program performance, even when two programs produce the same output. Each problem was approached first with a brute-force method and then improved using more efficient techniques, with execution times measured to compare the results.

## Overall Takeaway

Across all three problems, I observed that repeatedly performing unnecessary calculations can make programs extremely inefficient, especially as the input size increases. The biggest improvements came from changing the underlying approach rather than simply modifying individual lines of code. Techniques such as the Sieve of Eratosthenes, hash-based lookups, and binary search on the answer helped eliminate redundant work and significantly reduce execution time. Overall, the lab demonstrated that **choosing an efficient algorithm and the right data structure matters far more than making small code-level optimizations.**
